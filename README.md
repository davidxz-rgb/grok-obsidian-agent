Grok Obsidian Personal Agent
Personal desktop helper for my own use only.
It connects to:
My local Obsidian vault (notes on my computer)
Google Calendar (readonly) for briefings and planning
Gmail (readonly) when I ask the agent to look up a message
This is not a public product, SaaS, or mobile app store listing.  
I am the only intended user.
